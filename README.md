## Diretriz principal

**Abandonar a composição genérica do antigo painel administrativo.** Criar uma identidade própria de plataforma SaaS de agência, com referências sutis a redes sociais, publicação, calendário, criação de conteúdo e tecnologia. Usar menos textos, menos ilustrações decorativas, menos superfícies competindo por atenção. A identidade deve aparecer na composição, no ritmo visual e na experiência, não só em bordas e cores.

## Relação com o sistema real

- Repositório da aplicação: [ac-marketing-os](https://github.com/acmarketingcomercial-coder/ac-marketing-os).
- Estas imagens são **mockups ilustrativos**, não screenshots de uma aplicação implementada.
- **Não usar os nomes, horários, métricas, pessoas, thumbnails ou comparações ilustrativas como dados reais.**
- Preservar lógica, permissões, acessibilidade, dados, integrações e o ritual **Minuto de Sabedoria**.
- A implementação no sistema real exige avaliação visual, validação funcional e autorização própria. **Este repositório não autoriza merge ou deploy.**
