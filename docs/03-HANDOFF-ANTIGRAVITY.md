## Instrução principal

**Não copiar o Dashboard atual nem implementar literalmente os mockups exploratórios.**

O caminho desejado é uma interface clara, vinho/vermelho AC, elegante, moderna e mais minimalista do que as imagens geradas até aqui. O mockup `03-dashboard-light-cores-AC.png` é uma referência de identidade cromática; o `04-dashboard-light-AC-refinado.png` mostra um excesso de informações e ilustrações a evitar.

**Próximo marco:** consolidar e aprovar uma composição final de Dashboard minimalista antes de executar novo redesign abrangente.

## Entrega esperada

- Uma proposta visual substancialmente diferente da estrutura antiga, reduzida ao essencial.
- Fonte de dados e ações mapeadas, sem mock data na aplicação real.
- Compatibilidade desktop/mobile, acessibilidade e animações moderadas.
- Preservação do Minuto de Sabedoria e dos fluxos operacionais.
- Sem refatorar por refatorar. Testar as mudanças efetivamente afetadas.

## Governança

Não realizar merge, deploy no LAB ou produção por causa deste repositório de referências. O projeto de implementação possui regras próprias de branch, QA e autorização. Não criar GitHub Actions.

## Prompt de retomada sugerido

> Consulte `DesignSystem/README.md` e o briefing visual. Não volte ao layout antigo nem replique literalmente as explorações. A preferência atual é Dashboard claro com vinho/vermelho AC e menos informação simultânea. Primeiro alinhe um mockup minimalista; implemente somente após aprovação visual, preservando os fluxos existentes.
