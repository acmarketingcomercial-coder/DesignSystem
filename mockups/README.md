**Decisão mais recente:** o usuário achou que o último conceito continha **muita escrita, muitos desenhos e elementos simultâneos**. A versão definitiva deverá ser **mais limpa, minimalista, funcional, elegante e respirável**, sem perder a personalidade de agência/tecnologia.

Nenhum dos quatro PNGs, isoladamente, é o layout final aprovado. Ainda falta o mockup final simplificado.

### Atenção técnica

- Não inferir que thumbnails, nomes, horários, percentuais, KPIs e agendas dos mockups sejam dados reais.
- Não copiar interações ou canais ainda não suportados.
- Não confundir referência visual com screenshot do sistema real.
- Preservar Minuto de Sabedoria e a navegação operacional.
- Priorizar composição editorial e hierarquia em vez de multiplicar cards.

### Colocar os PNGs nesta pasta

Abra a pasta `mockups/` no GitHub, clique em **Add file → Upload files** e arraste os quatro PNGs originais (extraídos do pacote fornecido no chat). **Não enviar somente o ZIP**, pois o Antigravity precisa conseguir abrir cada imagem individualmente.

Os nomes acima devem ser preservados para manter as referências da documentação válidas.
